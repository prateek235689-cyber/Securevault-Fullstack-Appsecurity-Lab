# SecureVault — Full-Stack Application Security & Remediation Lab

## Project Overview:
SecureVault is a full-stack document management application being developed as a hands-on Application Security (AppSec) engineering project.
The project demonstrates how application security controls can be designed, tested, validated, and improved throughout the software development lifecycle.

## Objectives:
- Develop a functional full-stack web application.
- Implement secure user authentication and role-based access controls.
- Assess the application against relevant OWASP security risks.
- Perform manual HTTP security testing using Burp Suite.
- Document security findings with reproducible evidence.
- Apply code-level remediations and validate their effectiveness.
- Introduce automated security regression testing.

## Technology Stack:
 1. Frontend : React
 2. Backend : Node.js, Express.js
 3. Database : MongoDB
 4. Security Testing : Burp Suite Community Edition, OWASP Web Security Testing Guide
 5. Development : Visual Studio Code
 6. Version Control & Documentation : GitHub

## Planned Security Assessment Areas:
 1. Authentication and session management
 2. Broken access control
 3. Injection and input validation
 4. Security misconfiguration
 5. API authorization
 6. Vulnerable dependencies

## Project Status:
**Phase 1 — Repository setup and project planning**
Implementation, vulnerability assessment, remediation, and testing are in progress. Results will be added only after they have been verified.

## Ethical Testing Scope

All security testing is restricted to the locally hosted SecureVault application and test accounts created specifically for this project.

No unauthorized third-party systems will be tested.
